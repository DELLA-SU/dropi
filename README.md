# Dropi

이미지·PDF 변환과 용량 압축을 브라우저 안에서 처리하는 무료 웹 도구와 Mac 앱 다운로드 사이트.

- 웹사이트: https://della-su.github.io/dropi/
- 소유 계정: DELLA-SU
- 문의: ham2757@gmail.com

## 배포

치이카와 사이트와 같은 방식으로 `main` 브랜치의 `docs/` 폴더를 GitHub Pages에서 공개합니다. `docs/.nojekyll`로 정적 자산을 그대로 제공합니다. 홈페이지의 레이아웃은 기존 Dropi 승인 디자인을 유지했습니다.

웹사이트 소스 및 배포 파일만 포함합니다. macOS 앱의 Swift 소스는 이 저장소에 포함하지 않습니다. 설치 파일은 Apple 공증 전 테스트 버전입니다.

## 로컬 확인

상위 디렉터리 구조가 `/dropi/` 경로가 되도록 웹 서버를 실행하고 브라우저에서 확인하세요. 변환은 브라우저에서 실행하며 외부 파일 업로드 API를 사용하지 않습니다.

```sh
npm install
npm test
```

PDF 나누기는 파일 개수(페이지를 고르게 배분), 파일당 페이지 수, 한 페이지씩 저장을 지원합니다. 파일을 선택하면 전체 페이지 수와 분할 범위를 먼저 확인하며, 실행 후 개별 PDF 또는 ZIP을 내려받습니다. 웹 PDF 한도는 200페이지입니다.

변환 테스트는 200페이지 문서를 7개로 나눠 페이지 누락·중복·순서·회전을 확인하고, ZIP을 다시 열어 검사합니다. 이미지 변환, PDF 만들기·합치기·이미지 저장, 압축과 목표 용량, 오류·취소도 함께 검증합니다.

## 분석과 개인정보

Dropi 전용 GA4 속성의 공개 측정 ID를 사용합니다. `docs/analytics-config.mjs`의 호스트와 `/dropi/` 경로에서만 수집하며, 다른 GitHub Pages 프로젝트에서 시작하지 않습니다. 파일 내용·이름은 통계에 전송하지 않습니다. 쿠키에는 `dropi` 접두어와 `/dropi/` 경로를 사용합니다. 개인정보 페이지에서 통계 수집을 중지할 수 있습니다.

## 광고

AdSense 계정 확인 메타 태그만 포함합니다. 광고 스크립트는 포함하지 않습니다. `della-su.github.io`의 ads.txt는 기존 계정 설정을 그대로 사용하며, 프로젝트 경로의 ads.txt로 루트 파일을 대체할 수 없습니다. 사이트 심사 통과를 보장하지 않습니다.

## 유료 서비스로 전환할 때

GitHub Pages는 상업용 SaaS/거래 중심 서비스 호스팅을 제한합니다. 이 저장소는 현재 무료 테스트 배포를 위한 것입니다. 유료 서비스는 GitHub를 소스 저장소로 유지하고 적합한 별도 호스팅과 도메인에 배포해야 합니다.
