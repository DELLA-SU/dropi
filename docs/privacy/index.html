Dropi의 파일 처리 방식과 이용 통계, 문의 정보에 관한 안내예요. 시행일: 2026년 10월 30일.

변환하는 파일

선택한 파일의 변환·압축은 웹 브라우저 또는 Mac 앱 안에서 처리돼요. 파일 내용과 이름을 Dropi 서버에 업로드하거나 이용 통계로 보내지 않아요.

웹 결과는 브라우저 메모리에서 제공되며, 결과 지우기·페이지 닫기 등으로 해당 접근이 해제돼요. 직접 내려받은 파일과 원본 파일은 사용자의 기기와 다운로드 설정에 따라 관리돼요.

웹사이트 이용 통계

서비스 개선을 위해 Google Analytics 4를 이용해요. 페이지 조회, 사용한 기능, 처리 시작·완료·실패·취소, 결과 다운로드와 Mac 앱 다운로드 클릭을 기록해요. 기능 이름과 파일 개수 등 제한된 항목만 전송하며 파일 내용·파일명·오류 원문은 전송하지 않아요.

Google에는 이용 이벤트, 브라우저·기기 정보와 쿠키 식별 정보가 처리될 수 있어요. Google Signals와 광고 개인 최적화는 사용하지 않아요. 페이지 주소의 검색 매개변수와 해시를 통계에서 제외하고, 방문 출처는 도메인까지만 전송해요.

이 사이트의 통계 쿠키는 Dropi 경로에서만 사용하도록 설정하고, 이 코드에서 설정하는 만료 기간은 최대 1년이며 방문 때마다 연장하지 않아요. 브라우저의 삭제·차단 설정에 따라 더 일찍 제거될 수 있어요. Google 측 통계 데이터는 Google Analytics의 속성 설정과 정책에 따라 관리돼요.

이용 통계 선택

아래 버튼으로 이 브라우저에서 Dropi의 이용 통계를 중지하거나 다시 허용할 수 있어요. 선택은 브라우저 저장소에 기록되며, 저장소를 지우면 초기화돼요. Global Privacy Control 신호가 켜진 브라우저에서는 통계를 시작하지 않아요.

사이트 접속과 호스팅

이 웹사이트는 GitHub Pages에서 제공돼요. 웹페이지·앱 설치 파일·변환 도구를 불러올 때 GitHub에 접속하며, GitHub는 보안 목적으로 방문자의 IP 주소 등을 기록할 수 있어요. 이는 변환할 파일을 전송하는 것과는 달라요.
