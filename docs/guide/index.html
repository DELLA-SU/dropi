Dropi 사용 가이드

원하는 칸에 파일을 드롭하세요.

기능을 고르고 파일을 넣으면 변환이 시작돼요. 파일은 브라우저에서 처리하며, 완료 후 결과를 직접 다운로드해요.

1. 파일을 선택해요

홈 화면의 기능 칸을 클릭하거나 파일을 끌어 놓으세요. 여러 이미지를 PDF로 만들거나 PDF를 합칠 때는 시작 전에 파일 순서를 확인하고 바꿀 수 있어요.

2. 필요한 형식으로 바꿔요

PDF 만들기
여러 이미지를 하나의 PDF로 묶어요. 파일 순서가 페이지 순서가 돼요.
JPG 변환
HEIC·PNG 등 이미지를 JPG로 저장해요. 투명한 부분은 흰 배경으로 바뀌어요.
PNG 변환
이미지를 PNG로 저장해요. 원본에 투명한 부분이 있다면 유지해요. 배경을 새로 지우는 기능은 아니에요.
PDF 합치기
PDF 2개 이상을 선택한 순서대로 하나의 문서로 합쳐요.
PDF 나누기
PDF 각 페이지를 개별 PDF로 저장해요.
PDF → 이미지
각 페이지를 이미지로 저장해요. 원본 PDF의 텍스트 편집 기능을 이미지에서 이용할 수는 없어요.

3. 용량을 줄여요

‘용량 압축’ 탭에서 이미지 또는 PDF를 선택하세요. JPG의 ‘화질 우선·균형·용량 우선’은 품질과 용량의 절충 정도예요. 파일당 목표 용량을 입력하면 가능한 범위에서 자동 조절해요.

‘원본 해상도·PDF 구조 유지’를 켜면 이미지의 픽셀 수와 PDF의 구조를 유지하는 방식으로 처리해요. JPG는 재압축으로 화질이 달라질 수 있어요. 웹의 구조 유지 PDF 압축은 이미지 자체를 재압축하지 않아 감소 폭이 작을 수 있어요.

PDF 구조 유지를 끄면 페이지가 이미지로 바뀌어 텍스트 선택·검색, 링크·양식이 사라져요. 이미 최적화된 파일은 더 작아지지 않을 수 있고, 목표 용량 달성도 보장하지 않아요. 자세한 차이는 압축 설정 안내에서 확인하세요.

4. 결과를 다운로드해요

완료 후 각 파일의 ‘받기’를 누르세요. 결과가 여러 개라면 ‘모두 ZIP으로 받기’를 이용할 수 있어요. 저장 위치는 브라우저의 다운로드 설정을 따라요. 페이지를 닫기 전에 결과를 받아주세요.

웹에서 지원하는 범위

이미지: PNG·JPG·WebP·BMP·AVIF·HEIC·TIFF. 문서: PDF. HEIC·TIFF는 파일에 따라 처리되지 않을 수 있어요. 움직이는 GIF와 여러 페이지 TIFF는 웹에서 지원하지 않아요.

파일당 100MB, 한 번에 총 200MB·100개, PDF 200페이지, 이미지 1,600만 픽셀까지 처리할 수 있어요. 브라우저와 기기의 메모리에 따라 이보다 작은 파일도 처리되지 않을 수 있어요.

암호로 잠긴 PDF는 먼저 잠금이 해제된 사본을 준비해 주세요. 합치기·나누기로 양식이나 전자서명 정보가 유지되지 않을 수 있으니 중요한 문서는 원본을 보관하고 결과를 확인하세요.
