    설치가 안 된다면?

    DMG 파일을 열고 Dropi를 Applications(응용 프로그램) 폴더로 끌어 넣은 뒤 실행하세요. 현재 다운로드는 Apple 공증 전 테스트 버전이라 개발자를 확인할 수 없다는 보안 경고가 표시될 수 있어요. 이 페이지에서 받은 Dropi가 맞는지 확인한 뒤 아래 방법 중 하나를 따라 주세요.

    방법 1 · 경고창의 ‘?’에서 도움말 보기

    1. 보안 경고창에 ‘?’ 버튼이 있다면 눌러 macOS 도움말을 여세요.
    2. 도움말에 ‘개인정보 보호 및 보안 설정 열기’ 링크가 있으면 눌러 설정으로 이동하세요. 링크가 없거나 ‘?’가 보이지 않으면 방법 2를 따라 주세요.
    3. Dropi 차단 안내에서 ‘그래도 열기’를 누르고, 인증 요청이 나오면 Mac 로그인 암호 또는 Touch ID로 승인한 뒤 ‘열기’를 선택하세요.

    방법 2 · 시스템 설정에서 직접 열기

    1. Dropi를 한 번 실행해 보안 경고를 확인하고 닫으세요.
    2.  → 시스템 설정 → 개인정보 보호 및 보안 → 보안으로 이동하세요.
    3. Dropi 차단 안내의 ‘그래도 열기’를 누르고, 인증 후 ‘열기’를 선택하세요.

    macOS 12 Monterey에서는  → 시스템 환경설정 → 보안 및 개인 정보 보호 → 일반에서 확인하세요. 버튼이 보이지 않으면 앱을 다시 실행한 뒤 설정을 확인해 주세요. 화면과 버튼 이름은 macOS 버전에 따라 다를 수 있어요.

    ‘컴퓨터를 손상시킵니다’ 또는 ‘앱이 손상되었습니다’라는 경고라면 실행을 중단하세요. Apple 공식 안내 보기 ↗

    무료로 사용할 수 있나요?

    네. 웹에서 로그인 없이 무료로 변환할 수 있고, Mac 앱도 무료로 다운로드해 사용할 수 있어요.

    파일이 외부로 전송되나요?

    웹은 현재 브라우저에서, Mac 앱은 Mac 안에서 처리해요. 선택한 파일을 서버에 업로드하지 않아요. 원본은 바꾸지 않고 웹에서는 결과를 다운로드하고 앱에서는 지정한 폴더에 저장해요.

    서비스 개선을 위해 Google Analytics로 사이트 방문과 기능 이용 통계를 확인해요. 이 과정에서 쿠키와 브라우저·기기 정보, 이용 이벤트가 Google에서 처리돼요. 파일 내용·파일명은 통계로 보내지 않으며, Google Signals와 광고 개인 최적화는 사용하지 않아요. Google의 데이터 처리 안내 ↗

    어떤 기기에서 사용할 수 있나요?

    웹은 최신 Chrome·Edge·Safari·Firefox에서 설치 없이 사용할 수 있어요. 브라우저별 지원 형식과 메모리 한도로 일부 큰 파일은 처리되지 않을 수 있어요. Mac 앱 설치에는 macOS 12 Monterey 이상이 필요해요. Apple Silicon과 Intel Mac용 통합 설치 파일을 제공해요. Windows용 설치 앱은 없지만 웹 변환기는 이용할 수 있어요.

    압축 설정은 어떻게 선택하나요?

    압축 수준 · JPG 기준

    옵션차이
    화질 우선품질을 높게 유지해요. 용량 감소 폭은 작은 편이에요.
    균형화질과 파일 크기를 절충해요.
    용량 우선이미지 품질을 더 낮춰 파일 크기를 줄여요.

    아래 설정은 이런 뜻이에요

    원본 해상도 유지
    가로·세로 픽셀 수를 유지해요. JPG의 화질까지 그대로 보장하는 것은 아니에요.
    파일당 목표
    5 MB를 입력하면 파일 하나당 5MB 이하를 목표로 해요. 입력하면 압축 수준은 자동 조절로 바뀌어요.
    자동
    목표를 비워두면 선택한 압축 수준으로 처리해요. 목표를 달성하지 못하면 결과에 알려줘요.
    결과 저장
    웹에서는 변환 후 받기 버튼으로 저장해요. 앱에서는 저장 경로를 선택할 수 있어요.

    웹과 앱의 PDF 압축은 달라요

    웹의 구조 유지 모드는 PDF를 다시 저장해 기본 최적화해요. 이미지 자체를 다시 압축하지 않아 이미 최적화된 PDF는 줄지 않을 수 있어요. 구조 유지를 끄면 웹에서는 압축 수준과 관계없이 페이지를 이미지로 저장하므로 텍스트 선택·검색과 링크·양식이 사라져요. PDF 목표 용량은 달성을 보장하지 않아요.

    Mac 앱의 파일 형식별 차이

    해상도 유지를 켠 PDF는 세 압축 수준이 동일하게 처리돼요. 투명 PNG도 이 설정에서는 수준별 차이가 거의 없어요. PNG·PDF는 가능한 범위에서 최적화하며, macOS 13.4 이전에서는 PDF 압축 폭이 작을 수 있어요.

    해상도 유지를 끄면 이미지 크기도 줄어들 수 있어요. 이때 PDF에서 ‘용량 우선’을 선택하면 이미지 PDF로 저장돼 텍스트 선택·검색과 링크·양식 기능이 사라질 수 있어요.

    웹과 앱에서 지원하는 파일은 같나요?

    웹은 PNG·JPG·WebP·BMP·AVIF·HEIC·TIFF 이미지와 PDF를 처리해요. HEIC·TIFF는 파일에 따라 변환되지 않을 수 있으며, 여러 페이지 TIFF와 움직이는 GIF는 웹에서 지원하지 않아요. 파일당 100MB, 한 번에 총 200MB, PDF 200페이지, 이미지 1,600만 픽셀까지 처리할 수 있어요. 큰 파일은 Mac 앱을 이용해 주세요.

    암호로 잠긴 PDF는 잠금을 해제한 사본이 필요해요. PDF 합치기·나누기로 양식이나 전자서명 정보가 유지되지 않을 수 있으니 결과를 확인해 주세요. 웹 PDF 압축에서 구조 유지를 끄면 페이지 전체가 이미지로 바뀌어요.

    PDF 순서나 저장 폴더를 바꿀 수 있나요?

    네. 웹은 여러 파일을 선택하면 순서 확인창에서 위·아래 버튼으로 순서를 바꿀 수 있어요. 앱은 PDF 만들기·합치기 칸의 우클릭 메뉴를 이용해요. 앱 오른쪽의 저장 경로로 저장 폴더를 바꾸고, 웹은 브라우저의 다운로드 설정에 따라 저장돼요.
