Dropi 소개

파일 작업을 조금 더 간편하게.

Dropi는 이미지 변환과 PDF 작업, 용량 압축을 한 화면에서 처리하는 도구예요. 웹에서 바로 사용하거나 Mac 앱을 내려받아 사용할 수 있어요.

이런 작업을 할 수 있어요

이미지를 PDF로 만들기, JPG·PNG 변환, PDF 합치기·나누기·이미지 저장을 지원해요. 사진과 PDF의 용량 압축도 같은 방식으로 이용해요.

원하는 기능 칸에 파일을 드롭하거나 클릭해서 선택하세요. 작업이 끝나면 결과를 개별 파일이나 ZIP으로 받을 수 있어요.

내 파일은 내 기기에서

웹 변환은 브라우저 안에서, Mac 앱 변환은 Mac 안에서 처리해요. 변환할 파일을 Dropi 서버로 전송하지 않아요. 파일 이름과 내용도 이용 통계에 포함하지 않아요.

변환 결과는 원본과 별도로 저장해요. 파일 형식과 설정에 따라 화질, 투명 배경, PDF 기능이 달라질 수 있으니 결과를 확인해 주세요.

현재 제공 범위

웹 변환과 Mac 앱은 현재 무료로 제공돼요. 로그인이나 결제는 필요하지 않아요. Mac 앱은 macOS 12 이상에서 사용할 수 있는 Apple Silicon·Intel 통합 테스트 버전이며, Apple 공증 전이에요. 설치 안내는 다운로드 영역에서 확인하세요.

웹 처리 한도와 형식별 차이는 사용 가이드에서 확인할 수 있어요.
